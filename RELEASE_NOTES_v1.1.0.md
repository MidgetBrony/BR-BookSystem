# BR-BookSystem v1.1.0

## Changes

- Moves **Book Folder Location** out of BOXROOM's fixed Gameplay settings card.
- Uses the new standalone `ModsPanel.dll` API under **Mods > Mod Settings**.
- Removes the cloned vanilla settings row and its manual spacing/scroll fixes.
- Folder selection now applies immediately; **Refresh** rescans the library.

## Installation

Close BOXROOM and copy every file from the release's `Mods` folder into the
game's `Mods` folder. `ModsPanel.dll` is now required and is included in the
release. Remove the older `Boxroom_Books.dll` before starting the game.
