# BR-BookSystem 2.1.5

- Replaces the simplified vertical fold with the original PageFlip curl,
  clipping, easing, and moving-shadow system rotated into a top-to-bottom layout.
- Counter-rotates rendered CBZ, CBR, PDF, and EPUB pages before display so the
  artwork remains upright while the original reader turns the lower page upward.
- Uses the original book spine as the vertical layout's horizontal centre seam,
  eliminating the added gutter between pages.
